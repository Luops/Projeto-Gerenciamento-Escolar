# 📚 Sistema Escolar

Projeto para gerenciamento de alunos, turmas, professores e boletins.  
O sistema foi desenvolvido em **Java (Spring Boot + JPA/Hibernate)**, com foco em registrar, editar e consultar notas de alunos, além de calcular automaticamente aprovação ou reprovação.

## 📖 História do Usuário – versão 01.00 (29/09/2025)

### 1. Cadastro e organização
- Como professor, eu quero cadastrar uma turma, para que os alunos fiquem organizados por ano e número.  
- Como professor, eu quero cadastrar alunos, para que eles possam ser vinculados a uma turma e ter um boletim.  
- Como professor, eu quero criar um boletim, para que eu possa centralizar suas notas.  

### 2. Registro e edição de notas
- Como professor, eu quero registrar a nota de um aluno em determinada matéria, para que seu desempenho fique registrado.  
- Como professor, eu quero editar a nota de um aluno, para que eu possa corrigir erros ou atualizações.  
- Como professor, eu quero visualizar todas as notas de um aluno, para que eu tenha uma visão geral de seu desempenho.  

### 3. Matérias e professores
- Como professor, eu quero gerenciar as matérias que ministro, para que eu saiba em quais disciplinas sou responsável pelas notas.  
- Como professor, eu quero ver o total de alunos sob minha responsabilidade, para que eu consiga acompanhar minha carga de trabalho.  

### 4. Boletim e aprovação
- Como aluno, eu quero acessar meu boletim, para que eu veja minhas notas em cada matéria.  
- Como professor, eu quero que o sistema calcule automaticamente se o aluno foi aprovado ou reprovado, para que eu não precise fazer isso manualmente.  
- Como aluno, eu quero saber se fui aprovado, para que eu acompanhe meu desempenho escolar.  

### 5. Controle e auditoria
- Como administrador do sistema, eu quero que todas as entidades tenham data de criação e atualização, para que haja rastreabilidade de alterações.
